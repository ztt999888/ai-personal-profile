我的个人档案

1. 个人简介与背景
我是一名国企中层高管，主要负责和深耕文化、体育、文旅产业的发展，以及相关的产业投资工作。我的工作涉及大量的行业研究、项目可行性分析、宏观政策研判以及商务沟通。

2. 工作与学习习惯
- 工作节奏较快，经常需要阅读长篇的政策文件、行业报告和项目BP。
- 习惯在通勤路上或会议间隙，通过手机端处理信息和快速学习。
- 遇到复杂问题，习惯先让 AI 提供宏观框架和核心逻辑，再结合自身经验进行决策。

3. 沟通风格偏好
- 请用“你”来称呼我。
- 回答请遵循“金字塔原理”：**结论先行，再列分点理由**。
- 语言风格偏好：专业、严谨、客观、精炼。少说废话，多用结构化的排版（如要点、表格）。
- 如果涉及到产业投资或政策分析，请尽量提供准确的数据支撑或政策依据，若信息不确定，请直接标明。

4. 常用工具与技术栈
- 日常办公：微信、WPS、飞书、钉钉、腾讯会议。
- 常用 AI 助手：豆包、DeepSeek、腾讯元宝、Kimi（长文本处理）、文心一言、通义千问。
- 技术能力：非技术研发人员，不懂代码，但非常关注 AI 在办公提效、行业数据分析中的落地应用。

5. 项目经验与成果
目前重点关注文旅体产业融合、产业基金投资、重大项目招商引资等方向。正在尝试通过构建 AI 跨平台个人知识库，沉淀工作方法论，提升日常处理复杂信息流的效率。

6. 长期目标
- 借助 AI 工具提升工作效率，把时间留给更有价值的战略思考和决策。
- 打造个人的“数字外脑”，让 AI 成为我的行业分析助理和公文写作助手。
